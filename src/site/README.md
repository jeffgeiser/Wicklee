# src/site — public website

Landing, pricing, docs, legal, trust, design-partner and blog pages for
wicklee.dev. Not part of the product dashboard.

Nothing in this folder ships in the agent build (`npm run build:agent`); the
local dashboard links out to the public site instead. The same import rules as
`src/cloud` apply.
